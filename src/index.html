使用帮助

一、这是干什么的

本机常驻后，把 12 位本机密钥填到配对网页。之后在本程序或网页上对某台电脑点按钮，可唤醒、打开远程桌面、弹出网盘目录。

二、日常怎么用

  1. 启动程序，复制左上角本机密钥。
  2. 把密钥填到配对页，在本程序点点击注册（未注册）。
  3. 「注册人」出现名字后即可；可关窗口，程序留在托盘。
  4. 需要彻底退出时用退出程序或托盘菜单。

三、主机列表按钮（与原内嵌网页一致）

  • 唤醒：请求 wol.php?pcname=&lanmac=，把离线电脑叫醒。
  • 本地连接：用内网 IP 开远程桌面（原 id=iprdp 内网列）。
  • 远程连接：用路由/外网 IP 开远程桌面（原 id=iprdp 外网列）。
  • 网盘目录：按 data-dir 弹出资源管理器（原 id=opendir）。
  • 状态离线时点连接会提示「请先唤醒主机」，先点唤醒再连。
  • 列表 5 秒静默刷新，只改变化的格子，不会把页面卷回顶部。

四、托盘菜单

  • 显示窗口 / 点击注册 / 复制密钥 / 退出程序。

五、Mac 上能验证什么

功能Mac说明
界面、密钥、列表、静默刷新能浏览器或桌面壳都可
唤醒能发请求需能访问配置中的唤醒服务
远程桌面免密不能依赖 Windows 的 mstsc
网盘 UNC 弹资源管理器不能对等Mac 只能转访达 smb://
