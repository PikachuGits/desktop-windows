使用帮助

一、这是干什么的

本机常驻后可：注册密钥、接收打开目录指令、唤醒离线电脑、一键远程桌面、弹出网盘目录。

二、怎么用

  1. 复制本机密钥到配对页，点点击注册。
  2. 「注册人」有名字后可关窗，程序留在托盘。
  3. 列表里点唤醒 / 本地连接 / 远程连接 / 网盘目录。

三、远程桌面

Windows 用系统远程桌面；macOS 调用已安装的 Windows App（或 Microsoft Remote Desktop）打开 .rdp，即可连 Windows。首次可能需输入口令（配置里的 rdp 账号口令）。

四、自动更新

点右上角检查更新，有新版会从 GitHub Releases 下载安装并重启。发版请打 v* 标签并附带 latest.json 与签名。

五、配置文件

exe 同目录放 open-local-link.config.json（勿提交 git）。仓库内只有 example 模板。
